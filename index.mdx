Recap IA is a tool to manage documentation for Internal Audit teams running risk-based engagements.

## Getting Started

At it's core Recap IA is object oriented, meaning that each piece of data you interact with is related, whether that be an engagement, risk, control or anything else. As such, understanding Recap IA's data model is an essential to understanding how your data is tied together.
