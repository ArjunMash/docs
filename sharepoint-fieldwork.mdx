<Info>
  Recap IA's SharePoint integration is non-essential, and an optional client configuration. It provides an option for users to allow Recap IA to interoperate with a live-document store hosted in their organization's own environment.
</Info>

## How it works

Recap IA is the system of record for **cases and workflow**; SharePoint is the **document store**. The integration keeps the two in sync so auditors never hand-manage folders: as cases move through their lifecycle, folders and files are created automatically in your organization's SharePoint site, and each created item's ID is stored back on the case.

## Folder structure

When an Engagement is created, Recap IA creates a folder for it in the document library, along with subfolders. When each Test is created within the engagement, Recap IA creates a folder for that test and populates the workpaper template into it.

<Tree>
  <Tree.Folder name="{Engagement ID} {Engagement Name}" defaultOpen>
    <Tree.File name="Planning Memo.pdf" />
    <Tree.Folder name="{Test Name}" defaultOpen>
      <Tree.File name="{Test Name} Workpaper.xlsx" />
      <Tree.Folder name="Samples" />
    </Tree.Folder>
    <Tree.Folder name="Notes" />
    <Tree.File name="Audit Report.pptx" />
  </Tree.Folder>
</Tree>

| Event in Recap IA | What happens in SharePoint |
| --- | --- |
| Engagement is created | Engagement folder structure created |
| Test is created | Test folder created inside the engagement folder; workpaper template copied in as `{Test Name} Workpaper.xlsx` |
| Fieldwork | Assigned auditors get **edit** access to their workpaper and open it directly in Excel from the test case |
| Test submitted for review | Auditors' access is switched to view only; the reviewer receives a **view \+ comment** link. This locks workpapers once fieldwork is complete. |

## Access control

- **Auditors** assigned to a test get edit access to that test's workpaper during fieldwork.
- **Reviewers** (the engagement's Audit Manager) are able to review, view and comment once the workpaper is submitted.
- Sharing is managed by Recap IA through Microsoft Graph; no one on the audit team needs to manage SharePoint permissions by hand.

## Setup requirements

The integration connects through Microsoft Graph using an app registration in your organization's Entra ID tenant, granted `Sites.Selected` access (read and write) to the specific SharePoint site used for audit documents. This means Recap IA can only reach the site designated by Azure Admins.
